# Accessibility

## Commitment

MagicPort is designed to be usable by people with disabilities. We aim to meet
WCAG 2.1 AA for any web UI, with keyboard navigation, screen-reader friendly
markup, and color-contrast compliance.

## Supported Environments

- **Browsers**: Chrome, Firefox, Safari, Edge (latest two versions)
- **Assistive technology**: NVDA, JAWS, VoiceOver, TalkBack
- **OS/Device**: Windows, macOS, Linux, iOS, Android

## Known Limitations

- The project is currently a Laravel skeleton with minimal frontend
- No ARIA labels have been implemented yet
- No keyboard navigation testing has been performed
- Color contrast has not been audited

## How to Report Barriers

Use the [issue template](.github/ISSUE_TEMPLATE/bug.md) with the
`accessibility` tag, or email security@rasimaghayev.com. We will respond
within 72 hours for P2/P3 issues and within 24 hours for P0/P1 issues.

## Review Cycle

This statement is reviewed at least once per major version.
